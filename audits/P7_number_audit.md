# P7 number audit (paper B, main.pdf 47 pp, supplement.pdf 15 pp)

Date 2026-11-12. Nothing in the project was changed. Scratch scripts and extracts: `...\scratchpad\p7\` (cls.py, cls2.py, final.py, tabcheck.py, keycheck.py, figcheck.py, lit.py).

## Method
1. Text: PyMuPDF per page (main.txt, supplement.txt). Main reference list (from "References") excluded. Citation brackets `[n, m]` masked. Tokens attached to a letter (H5, K10, R1) are labels and skipped.
2. Ledger freshness: rebuilt in a scratch copy with `fill_ledger.py --strict` on all 14 files. Result: 482 placeholders, 0 literal warnings, identical rendered values, identical filled .tex (11 sections, floats, main, supplement). Only the `source_file_row` line numbers for `summary_secondary.csv` rows are stale (the CSV was edited at 03:12 after the 02:59 build; e.g. nonevent.sample.n_e3_excluded says row 1056, now 1083). Values are unaffected.
3. Source layer: all 460 numeric literals typed in the templates were listed and reviewed (below). Every other number in the .tex is a placeholder (482) or table/figure-script output.
4. PDF layer: every numeric token classified against (a) ledger_used.csv rendered values, (a2) values produced by table and figure scripts from ledger keys (value-matched to the four summary*.csv files), (b) ALLOW_LITERALS.txt, SPEC s9.4 and typed template literals, (c) citation within the sentence, (d) structural, (e) unexplained.
